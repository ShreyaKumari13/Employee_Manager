
# Employee Manager

**Employee Manager** is a robust HR web application designed to streamline the management of employee data. This application offers an intuitive interface and efficient backend operations, making it ideal for handling all aspects of employee information management.

## Tech Stack

- **Frontend:** HTML, CSS, ReactJS
- **Backend:** Spring Boot
- **Database:** MySQL (or your preferred database)

## Features

- Add, edit, and delete employee records
- View detailed employee information
- User-friendly and responsive design
- Scalable backend to handle large datasets
- CRUD functionality with seamless integration

## Installation and Setup

Follow these steps to set up and run the project:

1. **Download the Project Folder**  
   After downloading, you will find two folders:
   - `backend`: Contains the backend implementation using Spring Boot.
   - `frontend`: Contains the frontend implementation using ReactJS.

2. **Navigate to the Frontend Directory**  
   Change the directory to the frontend folder using the following command:

   ```bash
   cd em-project-view
   ```

3. **Install Dependencies**  
   Run the following command to install the required dependencies:

   ```bash
   npm install
   ```

4. **Run the Frontend**  
   Start the ReactJS development server with:

   ```bash
   npm start
   ```

5. **Run the Backend**  
   Open a new terminal, navigate to the `backend` folder, and start the Spring Boot application using your preferred IDE or with the following command:

   ```bash
   mvn spring-boot:run
   ```

6. **Access the Application**  
   Once both servers are running, open your browser and navigate to:

   ```
   http://localhost:3000
   ```

   (or the port specified for your React development server).
